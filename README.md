# Интернет-магазин на Django REST Framework (WB Test)

Тестовое задание для стажёра Backend-разработчика. Проект представляет собой REST API для интернет-магазина, включающий каталог товаров, корзину, личный баланс пользователей, оформление заказов, логирование и автоматическую документацию.

## Стек технологий
* **Python 3.12+**
* **Django 4+ / Django REST Framework**
* **PostgreSQL**
* **JWT Authentication** (`djangorestframework-simplejwt`)
* **drf-spectacular** (Swagger / OpenAPI документация)
* **Docker & Docker Compose**
* **Django Tests (unittest)**

---

## Основной функционал

1. **Пользователи:** Регистрация, авторизация (JWT), управление профилем, личный баланс (с возможностью пополнения).
2. **Товары:** Каталог товаров (название, описание, цена, количество на складе). Просмотр доступен всем, создание/редактирование/удаление — только администраторам.
3. **Корзина:** Добавление, удаление, изменение количества товаров и просмотр содержимого.
4. **Заказы (Checkout):** 
   * Создание заказа из текущей корзины.
   * Атомарная проверка остатков на складе и баланса пользователя.
   * Списание средств с баланса и уменьшение остатков товаров.
   * Очистка корзины и фиксация цен на момент заказа.
   * Логирование успешных заказов и ошибок.

## Как запустить проект через Docker Compose

Для запуска проекта на компьютере должны быть установлены **Docker** и **Docker Compose**.

1. Клонируйте репозиторий.
2. Убедитесь, что в корне проекта создан файл `.env` (пример ниже).
3. Запустите сборку и контейнеры одной командой:

```bash
docker compose up --build
```
